Програмне забезпечення: AllFusion Process Modeler (BPWin)

Предметна область

Моделюється процес розрахунку заробітної плати співробітників організації. Для розрахунку використовуються кадрові відомості, дані про відпрацьований час, тарифна сітка й правила нарахування. Результатом є інформація про заробітну плату за місяцями та розрахункова відомість. Метою роботи є моделювання бізнес-процесу; реальна база даних не створюється.

Контекстна модель IDEF0 з лабораторної № 3

A-0 «Розрахунок заробітної плати співробітників»

 ● Input: «Дані про співробітників».
 ● Control: «Тарифна сітка та правила нарахування зарплати».
 ● Mechanism: «Бухгалтерська інформаційна система».
 ● Output: «Розрахована заробітна плата за місяцями».

Аналіз: IDEF0 описує межі й керування процесом, але не деталізує інформаційні сховища та порядок окремих дій.

Декомпозиція DFD

Процес «Збір даних про співробітників» деталізовано на чотири етапи: отримання, перевірка, обробка даних, формування переліку співробітників. Передбачено сховище «Дані співробітників»; показано збереження перевірених відомостей та їх використання під час обробки.

Аналіз: DFD виявляє напрямки обміну та місце збереження інформації. Граничні вхідний і вихідний потоки на фотографії варто додатково перевірити щодо приєднання до процесів.

Декомпозиція IDEF3

Процес «Розрахунок заробітної плати» деталізовано так:

 1. Отримання даних про відпрацьований час.
 2. Визначення тарифної ставки.
 3. Обчислення заробітної плати.
 4. Формування результатів розрахунку.

Між етапами показано потоки «Дані про відпрацьований час», «Визначена тарифна ставка», «Розрахована заробітна плата».

Аналіз: IDEF3 демонструє лінійну послідовність розрахунку. Для розширеної моделі можна додати перевірку на помилки та альтернативні сценарії.
